# hydraulic

## hydraulic is a python based file compression utility.

*it uses gzip, zip and xz for backend.*

To download:
  Windows: https://hydraulic.sourceforge.io
  
  Source:
      clone the repo or atleast engine.py and gui.py, and run `python gui.py` or `py -version gui.py` where version is the version you want for example `-3.13`

Fully tested on windows

Future features: custom .hyd compression
